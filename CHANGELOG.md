# Novidades do SUMMER

Cada versão traz o que a loja passa a ver de novo. A versão só vai para produção depois de aprovada no teste de homologação.

## [0.1.0] — 2026-11-03 — Entrega 0: Fundação

Esta versão ainda não é usada no dia a dia da loja. Ela prepara a base do sistema.

### Novidades
- Agora dá para entrar no SUMMER com e-mail e senha, e sair quando quiser.
- Quem trabalha em mais de uma empresa troca de empresa pelo nome no topo da tela. Os dados de uma empresa nunca aparecem na outra.
- Cada pessoa vê no menu só o que pode usar: dono, balcão, estoque ou mecânico.
- Funcionário desativado perde o acesso na hora.
- O administrador do sistema cadastra uma loja nova, as empresas dela, liga as funções de cada empresa e convida o primeiro dono por um link que só vale uma vez.
- Cada pessoa troca a própria senha em "Minha conta".
- As telas funcionam no computador, no tablet e no celular.

### Melhorias
- Proteções contra tentativas repetidas de senha.
- O sistema avisa a hora de esperar quando alguém erra a senha muitas vezes.

### O que ainda não tem
- Peças, orçamentos, balcão, OS, estoque e notas aparecem como "Em breve" e chegam nas próximas entregas.
- O logo é provisório até a loja enviar os arquivos oficiais.
